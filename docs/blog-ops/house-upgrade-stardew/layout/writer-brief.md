#### H3 `Buying the 450 Wood changes the gold you bring`

罗宾的木材第一年 10g，第二年起 50g。450 木材等于 4,500g 或 22,500g。木材向罗宾买齐时，第一档一共 14,500g 或 32,500g。已经有 450 木材的人只带 10,000g 和这些木材。木材卖出价不随第二年的商店涨价一起涨。

例子写明假设：第一档、450 木材全部向罗宾买、没有另计其他花费。第一年带 14,500g；第二年或更晚带 32,500g。
