## 2. F-01：未用锄头开垦 / 可耕种格的适用范围

### 2.1 观察（页面实际写了什么）

1. 当前中文 **松果** 页正文把对象写成农场内外的松果种植，并同时要求未占用、可耕种和未被锄头开垦：
   - 正文片段：“农场内外任何未占用的可耕种方格中”。
   - 同段片段：“该方格必须未使用锄头开垦过”。
2. 同一中文 **松果** 页的 1.4 历史说明却写：“不再能放置在农场外部被开垦过的方格上。”这说明历史条目的对象范围明确是“农场外部”，不是所有地图位置的一条统一句子。
3. 中文 **松树** 页的 1.4 历史说明写：“在农场外种植树的种子不再需要用锄头翻地。”中文 **树** 页的 1.4 说明也写：“农场外种植树木种子不再需要耕地。”两条历史说明都把例外范围限定在农场外。
4. 官方 1.6 changelog 只实际写了两条地图限制：“You can no longer plant trees in the beach farm tunnel.” 和 “You can no longer plant trees in town.”它没有说明农场内外是否都需要先锄地，也没有改写松果页当前正文的“农场内外”句子。
5. 中文 **树肥** 页把树肥对象限定为已存在的“树种、树苗或小树”，并说明施肥树冬季可生长；它讨论的是种下之后的加速条件，不是松果初始种植格的锄地判定。

### 2.2 推断（明确标记，不当成已核验硬规则）

- 对**农场外**而言，已回读的两类历史说明可以同时成立：不再要求玩家先锄地，并且不能把树种放到已经锄过的农场外格子。这里要区分“是否需要执行锄地动作”和“已锄地格是否允许种植”，不能把“不需要锄地”解释成“已锄地也一定允许”。
- 当前中文松果正文把条件写成“农场内外 + 未占用可耕种格 + 未用锄头”；但本次没有找到带 `1.6.15` 逐条版本标记、专门解释农场内判定的官方说明。因此，农场外的历史边界可以交给 C，农场内则应保留“当前中文松果页正文口径”的限定，不扩写成全地图无差别规则。
- Wiki 首页的 `1.6.15` 版本标注不能把上述页面行自动变成“已按 1.6.15 逐页确认”。

### 2.3 结论：**部分边界已确认；整体仍 UNVERIFIED**

可确认的边界只有：

- 农场外：不需要先锄地，且不要把树种放在已经锄过的农场外格子；这是 1.4 历史说明的明确对象范围。
- 农场内：当前中文松果页正文写未占用的可耕种格且未用锄头，但本次没有单独的 `1.6.15` 官方逐条说明来扩大或收窄该页面口径。
- 1.6 官方明确的禁种地点是城镇和海滩农场隧道；不能用这两条去替代松果页面的农场内外细则。

### 2.4 给 C-zh 的最保守可发布句子

> 种松果时要按区域检查位置：农场外不需要先锄地，也不要把树种放在已经锄过的农场外格子；农场内可按当前中文松果页检查未占用、可耕种且未用锄头的格子。1.6 官方改动另明确城镇和海滩农场隧道不能种树。

这句话把“农场外的历史边界”和“农场内的当前页面口径”分开，没有宣称每一行都已由 `1.6.15` 官方补丁逐页锁定。C 不应把原 `C-zh:32` 的“未用锄头”扩成所有位置都相同的无条件规则。

## 3. F-04：Pine 专页第 3 阶段 vs 泛树页第 2 阶段

### 3.1 观察（对象和原文范围）

1. 中文 **松树** 专页的段落先限定对象：“位于农场外的松树也可以砍伐或放置树液采集器（不能在鹈鹕镇砍树）”。接着写，清除树桩且原格没有占用物后，每天 20% 概率在原位置生成“第三阶段的小树”。
2. 中文 **树** 泛页的“农场外”段落把对象扩大为：“所有农场外原本就存在的可以互动的树”。同段写，砍树并清除树桩后，每天 20% 概率重新生成“第2阶段的树苗”，之后正常成长；页面还列出煤矿森林、深山、铁路、巴士站和边远森林等可互动区域，并明确鹈鹕镇树木不能互动。
3. 两个页面都像是当前公开页面：松树页源页修改时间为 `2026-01-12T19:42:35Z`，树页为 `2026-05-19T14:22:57Z`；但两页都没有为 Stage 2/Stage 3 这句写出“适用于 1.6.15”的补丁标记。
4. 官方 1.6 changelog 只确认城镇和海滩农场隧道不能种树，并写到许多城镇树成为不能砍伐的实际树对象；没有说明自然松树清桩后的阶段，也没有裁决泛树页与松树专页的阶段差异。
5. 中文 **树肥** 页只说明已种下的树种/树苗/小树可施肥，以及施肥后冬季也可生长；它不规定农场外自然树清桩重生时从第 2 还是第 3 阶段开始。

### 3.2 推断（明确标记，不当成来源原句）

- 两个页面的对象范围并不完全相同：松树专页写的是“农场外的松树”这一 Pine 子集；泛树页写的是“农场外原本就存在的可互动树”这一更大的自然树集合。两者在农场外自然松树上发生重叠，因此不能仅用“对象不同”消除数字冲突。
- 松树专页的第 3 阶段和泛树页的第 2 阶段，也可能反映页面编辑/版本口径差异；现有公开页面和官方 1.6 总 changelog 没有提供足够证据选择其中一个作为当前 1.6.15 的无条件规则。
- 不启动游戏或存档实测，就不能把其中一个阶段数字提升为已验证的当前游戏行为。

### 3.3 结论：**未解决 / UNVERIFIED**

F-04 的冲突不能通过“松树专页优先”或“泛树页覆盖一切”来静默解决。可公开的范围边界是：

- Pine 专页数字只能归属于该专页明示的农场外自然松树对象；不能写成所有外部树或所有种植树苗的规则。
- 泛树页数字只能归属于该页明示的农场外原本存在、且可互动的普通树对象；不能无条件覆盖 Pine 专页的专属段落。
- 官方 1.6 的城镇/海滩农场隧道禁种限制不能被改写为自然树清桩重生阶段规则。

### 3.4 给 C-zh 的最保守可发布句子

> 如果处理农场外的自然松树，只能保守写：清除树和树桩、且原格没有被占用后，公开来源记载该位置可能重新生成小树；中文松树专页与泛《树》页对“第 3 阶段 / 第 2 阶段”的口径不一致，所以本文不发布阶段数字，也不把这条自然树规则扩展成城镇或海滩农场隧道的种植许可。

C 应删除或限定原 `C-zh:61` 的“第 3 阶段”数字；如果保留农场外自然树分支，至少要保留“自然松树对象”“来源口径冲突”和“没有游戏实测/1.6.15 逐页锁定”的边界。

## 4. 明确拒绝的写法

以下说法本次均**不允许**进入 C-zh：

1. “松果无论农场内外都必须种在未锄地格”或“松果任何地图都不需要锄地”。当前正文和 1.4 历史说明冲突，F-01 未解决。

3. “所有农场外自然树都从第 2 阶段重生”。泛树页的泛规则不能自动抹掉松树专页的专属段落。
4. “树肥能证明自然树重生从第 2/3 阶段开始”。树肥页的适用对象是已种下的树种、树苗或小树，不是阶段冲突裁决来源。
5. “这些页面都已逐页验证为 1.6.15”。Wiki 首页版本标注与各页面行的补丁适用性不是同一证据。
