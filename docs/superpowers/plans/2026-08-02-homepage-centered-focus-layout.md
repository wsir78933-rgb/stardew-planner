# Homepage Centered-Focus Layout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Center the existing homepage hero and independently narrow and center the existing trust section while keeping both sections in their current, separate page positions.

**Architecture:** Keep `HomepageContent` and its section order unchanged. Add only homepage-scoped CSS declarations to the existing hero and trust owners, then protect those declarations with focused source-contract tests and verify the real English and Simplified Chinese layouts in a production static build.

**Tech Stack:** Next.js 16 static export, React 19, TypeScript 5.9, CSS, Vitest 3, pnpm 10, local Hermes CDP browser.

## Global Constraints

- Implement the approved design in `docs/superpowers/specs/2026-08-02-homepage-centered-focus-layout-design.md` exactly.
- Keep the hero before `plannerWorkspace` and keep the trust section after the FAQ and before the footer.
- Never move, merge, duplicate, wrap together, or create a shared layout owner for the hero and trust sections.
- Preserve all fonts, font sizes, line heights, colors, borders, copy, buttons, vertical section spacing, and the current hero glow.
- Do not add images, illustrations, fact lists, cards, copy fields, components, wrappers, dependencies, breakpoints, or locale-specific CSS.
- Modify only `app/globals.css` and `tests/homepage/homepage-style-contract.test.ts`.
- Treat `src/components/homepage-content.tsx` as read-only and prove its contents are unchanged after implementation.
- The authorized files already contain user-owned uncommitted changes. Patch their current contents narrowly; never reset, restore, stash, reformat wholesale, or replace them.
- Work in the current checkout. Do not create a worktree because the approved baseline includes the current uncommitted tree.
- Do not commit, stage, push, deploy, install dependencies, or modify any lockfile.
- Stop immediately if implementation requires any file or behavior outside this plan.

- [ ] **Step 3: Verify English desktop geometry at `1440x900` and `1920x1080`**

At each viewport, evaluate this browser probe:

```js
(() => {
  const hero = document.querySelector("[data-homepage-hero]");
  const heroHeading = hero?.querySelector("h1");
  const workspace = document.querySelector("[data-homepage-workspace]");
  const faq = document.querySelector("#faq");
  const trust = document.querySelector("[data-homepage-trust]");
  const footer = document.querySelector("[data-homepage-shell] > footer");

  if (!hero || !heroHeading || !workspace || !faq || !trust || !footer) {
    throw new Error("Missing homepage layout owner during centered-focus verification");
  }

  const heroRect = hero.getBoundingClientRect();
  const headingRect = heroHeading.getBoundingClientRect();
  const workspaceRect = workspace.getBoundingClientRect();
  const faqRect = faq.getBoundingClientRect();
  const trustRect = trust.getBoundingClientRect();
  const footerRect = footer.getBoundingClientRect();
  const heroStyle = getComputedStyle(hero);
  const trustStyle = getComputedStyle(trust);

  return {
    heroDisplay: heroStyle.display,
    heroDirection: heroStyle.flexDirection,
    heroAlignment: heroStyle.alignItems,
    heroTextAlignment: heroStyle.textAlign,
    heroHeadingCenterDelta: Math.abs(
      headingRect.left + headingRect.width / 2 - window.innerWidth / 2,
    ),
    trustCenterDelta: Math.abs(
      trustRect.left + trustRect.width / 2 - window.innerWidth / 2,
    ),
    trustWidth: trustRect.width,
    trustMaxWidth: trustStyle.maxWidth,
    orderIsPreserved:
      heroRect.top < workspaceRect.top &&
      faqRect.top < trustRect.top &&
      trustRect.top < footerRect.top,
    horizontalOverflow:
      document.documentElement.scrollWidth > document.documentElement.clientWidth,
  };
})()
```

Expected at both desktop viewports:

- `heroDisplay` is `flex`.
- `heroDirection` is `column`.
- `heroAlignment` is `center`.
- `heroTextAlignment` is `center`.
- `heroHeadingCenterDelta` is at most `1` CSS pixel.
- `trustCenterDelta` is at most `1` CSS pixel.
- `trustWidth` is at most `768` CSS pixels.
- `trustMaxWidth` resolves to `768px`.
- `orderIsPreserved` is `true`.
- `horizontalOverflow` is `false`.

Also visually confirm the centered composition is optically balanced and the trust borders end around the narrow strip rather than extending across the wide page container.
