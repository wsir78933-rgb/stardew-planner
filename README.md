# Stardew Valley Farm Planner

A bilingual, browser-based farm layout planner for Stardew Valley.

- Live site: [stardewvalleyplanner.art](https://stardewvalleyplanner.art)
- Repository: [github.com/wsir78933-rgb/stardew-planner](https://github.com/wsir78933-rgb/stardew-planner)
- Languages: English and Simplified Chinese

> This is a fan-made project. It is not affiliated with or endorsed by
> ConcernedApe or Stardew Valley.

## About

Stardew Valley Farm Planner helps players design farm layouts directly in the
browser. Projects are stored locally in the current browser, so no account or
cloud sync is required.

## Features

- Plan all eight official farm types, with Ginger Island also available in the
  map picker.
- Place buildings, crops, decorations, and other supported items.
- Switch between spring, summer, fall, and winter.
- Visualize sprinkler, scarecrow, Bee House, and Junimo Hut coverage.
- Create and save multiple projects in the current browser.
- Import a Stardew Valley save file on an experimental basis.
- Export farm layouts as standard- or high-quality images.
- Browse English and Simplified Chinese farm guides and articles.

## Technology

- Next.js 16
- React 19
- TypeScript 5
- PixiJS 8
- Tailwind CSS 4
- pnpm 10

## Local development

### Requirements

- Node.js 20.9.0 or newer
- pnpm 10.22.0 or a compatible pnpm 10 release

### Setup

```bash
git clone https://github.com/wsir78933-rgb/stardew-planner.git
cd stardew-planner
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Available checks

```bash
pnpm typecheck
pnpm build
pnpm test
```

# 星露谷物语农场规划器

一个支持英文和简体中文的、在浏览器中使用的《星露谷物语》农场布局规划工具。

- 在线网站：[stardewvalleyplanner.art](https://stardewvalleyplanner.art)
- GitHub 仓库：[github.com/wsir78933-rgb/stardew-planner](https://github.com/wsir78933-rgb/stardew-planner)
- 支持语言：英文和简体中文

> 这是一个玩家制作的非官方项目，与 ConcernedApe 或《星露谷物语》官方不存在隶属、
> 授权或认可关系。

## 项目简介

本项目用于帮助玩家直接在浏览器中设计农场布局。项目数据保存在当前浏览器本地，
不需要账号或云同步。

## 主要功能

- 规划八种官方农场类型，地图选择器中还提供姜岛。
- 放置建筑、作物、装饰和其他已支持的物品。
- 在春、夏、秋、冬四个季节之间切换。
- 查看洒水器、稻草人、蜂房和祝尼魔小屋的覆盖范围。
- 在当前浏览器中创建并保存多个项目。
- 实验性导入《星露谷物语》存档。
- 将农场布局导出为标准或高画质图片。
- 浏览英文和简体中文农场指南及文章。

## 技术栈

- Next.js 16
- React 19
- TypeScript 5
- PixiJS 8
- Tailwind CSS 4
- pnpm 10

## 本地开发

### 环境要求

- Node.js 20.9.0 或更高版本
- pnpm 10.22.0 或兼容的 pnpm 10 版本

### 启动项目

```bash
git clone https://github.com/wsir78933-rgb/stardew-planner.git
cd stardew-planner
pnpm install
pnpm dev
```

在浏览器中打开 [http://localhost:3000](http://localhost:3000)。

### 可用检查命令

```bash
pnpm typecheck
pnpm build
pnpm test
```
